# Perceptron Neural Network

## Overview

This repository contains an implementation and study of the
Perceptron Learning Algorithm for binary classification.

## Objectives

- Understand the Perceptron Learning Algorithm
- Implement a basic Perceptron model
- Understand weights, bias, and the learning rate
- Perform binary classification
- Visualize the classification results

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook
